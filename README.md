### 🌐 Web Apps & Services

- [**YouTube Downloader Site**](https://youtubedownload.psannetwork.net/)

  クラウド上に変数を保存し、複数クライアントから簡単に扱える JavaScript ライブラリ。  
  小規模なリアルタイムアプリや簡易バックエンドに最適です。

- [**Chatcode**](https://github.com/psannetwork/Chatcode)  
  コード共有とチャットが同時にできる、軽量なコラボレーションツール。  
  勉強会やペアプロ、オンライン授業などでの利用を想定しています。
